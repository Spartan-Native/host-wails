04 Spartan Native · host adapter

Go + Wails, the real OS.

A Go service that reads the accent, light/dark, contrast, transparency, motion, text size and window focus from the operating system itself, and pushes every change to your Angular app as it happens. It also gives the frontend native window controls, menus and dialogs.

Windows · macOS · Linux Wails v3 passes host-conformance
Get started
$ npm i @spartan-native/host-wails
main.go 
import spartannative "github.com/spartan-native/host-wails"

app := application.New(application.Options{
	Services: []application.Service{
		application.NewService(spartannative.New()),
	},
})
app.config.ts 
import { isWails, wailsHost } from '@spartan-native/host-wails';
import { webHost } from '@spartan-native/host-web';

provideSpartanNative({ host: isWails() ? wailsHost() : webHost() });

How it works

Two halves, one tag.

A Go module and an npm package, released together from the same git tag. They talk over the Wails runtime: bound methods one way, events the other.

The Go service reads the OS

One reader per OS: the registry and SystemParametersInfo on Windows, AppKit on macOS, the XDG desktop portal on Linux. It listens for theme changes and polls the settings that send no notification.

Changes cross as events

When something actually changed, the service emits spartan-native:appearance. A chosen native menu item comes back as spartan-native:menu-action. Nothing is sent when nothing changed.

wailsHost() feeds the theme

The TypeScript adapter implements the NativeHost contract from @spartan-native/theme. Components never know they run in Wails, so the same frontend still works in a browser.

Quick start

Three steps in an existing Wails v3 app.

Set up Spartan Native first (theme, styles). Then install both halves at the same version.

1 · Install

terminal 
npm install @spartan-native/host-wails \
  @spartan-native/host-web \
  @wailsio/runtime
go get github.com/spartan-native/host-wails

2 · Register the service

main.go 
app := application.New(application.Options{
	Services: []application.Service{
		application.NewService(spartannative.New()),
	},
	// …
})

3 · Provide the host

app.config.ts 
export const appConfig = {
  providers: [
    provideSpartanNative({
      host: isWails() ? wailsHost() : webHost(),
    }),
  ],
};

For your own title bar, make the window frameless on Windows and Linux and use the hidden-inset title bar on macOS. <sn-title-bar> and <sn-window-controls> from @spartan-native/desktop-ui then drag, minimize, maximize and close the real window.

Window, menus, dialogs

The OS's own, not imitations.

Window

Focus, minimize(), toggleMaximize(), close() and the maximized state come from the Wails window API. desktop-ui's window buttons use them automatically.

Menus

Application and context menus built from plain MenuItem data: checkbox and radio items, submenus, roles like editMenu, and portable accelerators such as mod+shift+s. <sn-menubar> becomes the macOS global menu bar.

Dialogs

openFile, saveFile, pickFolder and message show the OS's own dialogs, attached to the window (a sheet on macOS). A cancelled dialog gives [] or null, never an error.

backup.component.ts 
const host = inject(NATIVE_HOST);

const [file] = await host.dialogs!.openFile({
  filters: [{ name: 'Backups', extensions: ['hbk'] }],
});

const answer = await host.dialogs!.message!({
  kind: 'question',
  message: 'Save changes?',
  buttons: [
    { id: 'save', label: 'Save' },
    { id: 'discard', label: "Don't save" },
    { id: 'cancel', label: 'Cancel' },
  ],
  defaultId: 'save',
  cancelId: 'cancel', // always pass one: GTK can close an alert without a button
});
Options & debugging

Sensible defaults. Two knobs.

  • WithSkin forces a skin, for example from a user setting
  • WithPollInterval sets how often settings without a change notification are checked (default 1 s; zero turns polling off)
  • SPARTAN_NATIVE_DEBUG=1 logs every call and every change
  • Tests without Wails: wailsHost({ runtime: fake }) and describeHostConformance from @spartan-native/host-conformance
main.go 
spartannative.New(
	spartannative.WithSkin("gtk"),
	spartannative.WithPollInterval(500*time.Millisecond),
)
Built to be trusted

Small, tested, and checked from both sides.

✓

Conformance suite

The adapter passes @spartan-native/host-conformance, like every host.

⇄

Shared fixtures

Go and TypeScript are tested against the same names and JSON values.

⏱

Never hangs

Portal reads give up after 2 s; a late D-Bus session is picked up later.

Δ

Quiet

An event only when a value actually changed. No reload, no flicker.
